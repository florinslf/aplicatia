# Cowork OS

Spațiu de lucru organizat pe proiecte.

## Structură

```
Cowork OS/
├── _Templates/          ← template-uri reutilizabile (docx, xlsx, pptx)
├── _Arhiva/             ← proiecte finalizate
└── Nume Proiect/
    ├── Documente/       ← Word, PDF
    ├── Date/            ← Excel, CSV
    └── Rapoarte/        ← output-uri finale
```

## Cum adaugi un proiect nou

1. Creează un folder cu numele proiectului
2. Adaugă subfolderele: `Documente`, `Date`, `Rapoarte`
3. Când proiectul e finalizat, mută-l în `_Arhiva`
